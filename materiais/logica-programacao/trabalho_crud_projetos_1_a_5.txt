# TRABALHO PRÁTICO — SISTEMA CRUD EM LINGUAGEM C

## 1. Tema do trabalho

Desenvolvimento de um sistema CRUD em linguagem C com armazenamento de dados em arquivo de texto.

Cada grupo ficará responsável por desenvolver um dos cinco projetos apresentados neste documento.

## 2. Objetivo

O objetivo deste trabalho é aplicar, de forma prática, os conhecimentos estudados durante as aulas:

* Criação e utilização de `struct`;
* Vetores de estruturas;
* Funções;
* Ponteiros;
* Laços de repetição;
* Estruturas condicionais;
* Menu com `switch`;
* Busca de registros;
* Cadastro de dados;
* Atualização de dados;
* Exclusão de registros;
* Manipulação de arquivos de texto;
* Salvamento e carregamento automático dos dados.

Além de praticar programação, cada grupo deverá desenvolver uma solução capaz de ajudar na resolução de um problema real.

## 3. Organização dos grupos

O trabalho será realizado em grupos.

Cada grupo receberá um dos seguintes projetos:

1. Agenda de contatos;
2. Sistema de achados e perdidos;
3. Biblioteca da turma;
4. Controle de estoque da cantina;
5. Empréstimo de equipamentos.

Todos os integrantes deverão participar do desenvolvimento e conhecer o funcionamento do código.

Durante a apresentação, o professor poderá fazer perguntas para qualquer integrante do grupo.

## 4. O que é um CRUD?

CRUD representa as quatro operações básicas realizadas sobre dados:

* **Create:** cadastrar um novo registro;
* **Read:** consultar ou listar os registros;
* **Update:** atualizar um registro existente;
* **Delete:** excluir um registro.

Portanto, todos os projetos deverão obrigatoriamente permitir cadastrar, consultar, atualizar e excluir informações.

# PROJETO 1 — AGENDA DE CONTATOS

## Situação-problema

Uma pessoa precisa organizar seus contatos pessoais e profissionais. Atualmente, os nomes e telefones estão anotados em diferentes papéis e mensagens, dificultando a localização das informações.

O grupo deverá desenvolver uma agenda digital que permita cadastrar e gerenciar contatos.

## Exemplo da `struct`

```c
struct Contato {
    int codigo;
    char nome[50];
    char telefone[20];
    char email[50];
};
```

7. Salvar os contatos em um arquivo de texto;
8. Carregar os contatos quando o programa for iniciado;

# 5. REQUISITOS OBRIGATÓRIOS PARA TODOS OS PROJETOS

Independentemente do projeto recebido, o programa deverá:

2. Utilizar um vetor de estruturas;

4. Possuir um menu principal;

10. Atualizar registros;

15. Salvar os registros em um arquivo `.txt`;
16. Carregar automaticamente os registros ao iniciar;
17. Atualizar o arquivo após cadastrar, alterar ou excluir;
18. Permitir nomes e descrições com espaços;
